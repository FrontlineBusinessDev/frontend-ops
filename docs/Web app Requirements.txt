User Roles
Use these roles consistently across the system:
Super Admin — FBS/system administrator
Company Admin — client/company administrator
HR Admin — manages employees, attendance, leave, etc.
Payroll Admin — processes and manages payroll
Manager — approves employee requests
Employee — uses Employee Self-Service
For the UI prototype, Claude should prioritize the Company Admin, HR/Payroll Admin, Manager, and Employee experiences. Super Admin features can be treated as SaaS administration later.

SaaS Requirement
Every client/company should have an isolated workspace:
FBS OPS
   ├── Company A
   │    ├── Employees
   │    ├── Payroll
   │    └── Reports
   │
   ├── Company B
   │    ├── Employees
   │    ├── Payroll
   │    └── Reports
   │
   └── Company C
Users must never access another company's data.
